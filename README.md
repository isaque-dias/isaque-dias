## ⚡ Área de Atuação

Trabalho no universo da **automação de sistemas de distribuição de energia (ADMS)**, que envolve:

- Supervisão em tempo real de ativos de campo (religadores, chaves seccionadoras, transformadores, banco de capacitores)  
- Operação de funções DMS: **FLISR**, **VVO**, **State Estimation**  
- Protocolos de comunicação industrial: **DNP3**, **IEC 101/104**, **IEC 61850**  
- Integração entre sistemas: **ADMS ↔ GIS ↔ SAP ↔ OMS**


## 🌱 Interesses Técnicos

- **Automação e SCADA**: EcoStruxure ADMS, Elipse Power, CWSi  
- **Programação**: Python (automação, análise de dados), SQL Server, Bash  
- **Redes elétricas**: Topologia de distribuição, proteção e coordenação, qualidade de energia  
- **Linux**: Administração de sistemas, scripts de automação  
- **Desenvolvimento de Sistemas**: Java, Spring Boot, HTML, CSS, JavaScript (base acadêmica)
